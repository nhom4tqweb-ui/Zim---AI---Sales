# BRAND IDENTITY GUIDELINES FOR ZIM SALES AI DEMO

- Framework: HTML5 + Tailwind CSS (dùng CDN Tailwind cho nhanh, không cần cài đặt phức tạp)
- Primary Color: Red ZIM (#B91C1C) -> Class: `bg-red-700`, `text-red-700`
- Tech/AI Color: Indigo (#4F46E5) -> Class: `bg-indigo-600`, `text-indigo-600`
- Neutral Font: Inter / Sans-serif -> Class: `font-sans text-slate-800`
- Background: Light Gray (#F8FAFC) -> Class: `bg-slate-50`
- Component Box: Rounded 16px (`rounded-2xl`), White Card (`bg-white`), Thin Border (`border border-slate-200`), Shadow nhẹ (`shadow-sm`)
- Call-to-action Button: `bg-red-700 hover:bg-red-800 text-white font-medium py-3 px-6 rounded-xl transition duration-200`
- AI Badge: `inline-flex items-center gap-1.5 py-1 px-3 rounded-full text-xs font-semibold bg-indigo-50 text-indigo-700 border border-indigo-200`
